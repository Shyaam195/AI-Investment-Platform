\# AI Investment Platform



An AI-powered investment analysis platform built using Python, Streamlit, Machine Learning, and Scikit-learn.



\## Features



\- AI-based investment scoring

\- Market cap prediction

\- Risk analysis

\- Investment recommendation engine

\- Interactive dashboard

\- Machine Learning model integration



\## Technologies Used



\- Python

\- Streamlit

\- Pandas

\- Scikit-learn

\- Joblib
